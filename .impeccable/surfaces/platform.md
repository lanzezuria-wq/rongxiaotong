# 融销通全站改版

## Direction contract

THESIS: 用同一农业品牌连接产品浏览、三人联保与专业管理。门户让人理解业务，工作台让人完成任务。

OWN-WORLD: 深绿、白色与浅中性色；中文门户标题、清晰业务正文；照片、商品与成员是主要视觉内容。保留用户批准的设计方向，catalog seed f0e3d12a604c0a84526d553376cd2d15 中数据艺术和唱片方案与已确认方向不符；机场标识仅启发清晰的下一步指引，不采用其色彩和装饰。

STRUCTURE: 门户导航、左右分区首页、内容列表、流程型表单；后台浅色侧栏与紧凑工作区。移动端导航折叠、内容单列、表格容器内滚动。

SIGNATURE: 三人联保成员席位把成组条件直接呈现；首页三个服务入口连接实际路由。

BEHAVIOR: 所有按钮使用现有 API 或真实路由；区分加载、空数据、失败、权限与完成。现有 29 页全部适配，新增操作审计页单列。

PROOF: 隔离 MySQL 集成回归、真实浏览器三尺寸截图、关键链路交互与前后构建比较；不以静态样图替代功能。
